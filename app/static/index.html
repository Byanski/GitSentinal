Remediation Guide

How to safely remove this secret

1 Rotate or Revoke Immediately

Once committed to GitHub, assume this secret is compromised. Revoke it on the provider's dashboard (e.g. AWS, OpenAI, Stripe) and generate a replacement.

2 Purge from Git History

Simply deleting the line in a new commit is not sufficient because the key remains in your git history! Use `git-filter-repo` to permanently erase it:

git filter-repo --invert-paths --path <FILE_PATH>

3 Store in `.env` or GitHub Secrets

Place sensitive variables inside a local .env file, add .env to your .gitignore, and configure production secrets under Repo Settings > Secrets and Variables on GitHub.
